# PPT Workbench Review Cases

Use relevant cases to sharpen a review. These generalized examples are not a
style default, mandatory page order, clinical source, automatic pass rubric or
permission to copy private project artwork. Current source and actual pixels
remain the evidence. Use the public fixture below for structural transport tests;
use authorized real images for visual evaluation.

| Case | Deceptively acceptable result | Necessary judgment and repair |
| --- | --- | --- |
| Strategic pivot | An attractive slide about distributing specialist work replaces a page about rapidly improving general AI | Read the source argument and neighbors. Restore the strategic alternatives and preferred endpoint; topic overlap is not correspondence. |
| Essential comparison | Translation retains a heading about healthcare but drops medical capability versus care delivery | Preserve both sides and the relationship visibly. Notes alone cannot replace the defining comparison. |
| Ink continuity | Paper texture, mountains and bamboo surround flat bright icons | Judge mark-making, washes, lettering, material and space against current accepted references. Remove arbitrary decoration; retain the visual tradition through actual painting treatment. |
| Local style repair | A cleaner page changes to a warm background, dense color panels and rigid printed lettering | Compare old/new and neighbors. Improve craft within the selected visual language; do not equate minimalism with better fit. |
| Object semantics | A microscope is drawn for an exchangeable AI foundation | Specify the intended object and action before redraw. Inspect the whole revised page for changed labels, anatomy and arrows. |
| Medical evidence | A modality label is correct but the displayed organ or view is wrong; generated plots add unsupported error bars | Compare with verified anatomical/evidence sources. Remove invented results; no aesthetic improvement compensates for factual distortion. |
| Concise talk | Background motivation disappears while product names remain | Restore why the audience needs the method, merge repetition and add a bridge if necessary. A page budget is not permission to break the causal chain. |
| Quiet regression | The new image is correct, but notes or a handoff copy still use the earlier revision | Read actual final page order, media, notes and declared copies. Preserve approved media equivalence rather than repeatedly re-reviewing identical pixels. |

For initial-quality evaluation, retain the first generated image before any
refinement and review it separately. Use the same brief/source/reference roles
for baseline and candidate, blind the ordering when comparing, and report
unresolved or unassessed dimensions. The evidence helper validates image/ref
binding and summarizes observations supplied by RCA; it does not decide which
argument is correct or which painting is better.
