# Visual Truth Boundaries

RCA is the owner for visual-domain truth. OPL generated surfaces consume descriptors and refs for discovery, scheduling, projection, and handoff.

RCA-owned bodies and verdicts:
- source readiness judgment
- communication strategy acceptance
- visual direction acceptance
- review/export verdict
- canonical artifact authority
- product visual knowledge and visual-pattern accept/reject judgment
- owner receipt

OPL-owned shells:
- generated CLI/MCP/Skill/product-entry/status/session/domain_action_adapter/workbench descriptors
- generic provider-backed attempt runtime
- typed queue, retry, dead-letter, and operator projection
- generic artifact gallery or handoff shell over RCA refs

Private owner, topic and project knowledge keeps its single editable source in
the user's selected library or working directory. Framework can resolve that
authorized source, freeze an exact execution snapshot and apply an accepted
version-checked update. Those mechanics neither transfer private body ownership
to RCA nor grant Framework semantic or visual-verdict authority.
