# PPT Source Adaptation

Applies to source intake, story planning and semantic review of an existing deck,
translation, visual restyling or concise lecture. These are reusable methods;
the current user request determines which content may change.

## Preserve The Right Thing

Establish the actual accepted source deck and page order from the current entry,
not a filename, modification time, same page count or an old plan. Read the source
pages themselves: a manifest that says “aligned” is not semantic evidence.

For each target page, keep a stable id and record source-page refs, page duty,
core argument, essential comparison or mechanism, supported evidence, incoming
question and outgoing transition in the existing blueprint. A translation or
style-only revision preserves these relationships even when wording changes.
Do not substitute a nearby page's topic merely because its labels are similar.
An approved narrative does not freeze every sentence when content improvement
is authorized; record which parts the current request actually protects.

For a shorter talk, permit many-to-one source mapping, merged explanations and
new bridge pages. Compress repetition and evidence depth while retaining the
motivation needed to understand the next method. A spoken transition cannot
replace a missing visual premise. Treat approximate page counts as flexible
only when the user does; budget pauses and distinguish rehearsal estimates
from observed delivery time.

## Keep Evidence Meaning

Separate primary results, explanatory illustrations and speaker synthesis.
Bind quantities to task, cohort, metric, comparison and experiment conditions.
Do not merge incompatible results, confuse percent with percentage points,
or attribute treatment/function/survival benefit to a model score. Distinguish
training inputs from actual inference inputs and a proposed organization from
an implemented or clinically validated system.

Keep necessary methods, comparisons and key results visible. Notes explain;
source records preserve full titles, DOI and conditions. Compact journal/year
attribution may fit both method and result pages when the brief allows it.
Full public names and required product order follow the user's naming policy.

Visible copy addresses the audience. A planner's purpose field, internal source
id, workflow instruction or production caveat is not slide copy. Preserve the
speaker's actual role rather than narrating their own work as a third party.

## Review Decision

Read each target page against its source duty and immediate neighbors. Ask what
the viewer can infer from the visible objects, comparisons and arrows. Similar
titles, keyword overlap and matching page counts cannot prove correspondence.
For a repeated semantic error, inspect related uses before selecting repair ids.
Unsupported source gaps remain explicit gaps; improve wording without inventing
evidence. Source mappings belong to this deliverable, not a universal deck order.
