# PPT Image-First Page Prompt

Use the current accepted blueprint and visual direction. The complete-page
container does not select an aesthetic, language, title formula or density quota.

## Reference And Content Binding

Keep the current page's stable id, source-page refs, role, argument, required
comparisons and transition in the authoring record. For translation/restyling,
preserve those duties; for a concise adaptation, bind the source-page collection
and explain any merge or new bridge. Do not give the model an entire deck's
unfiltered content when only one page is being authored.

Label supplied images by role: content baseline, style, anatomy, verified asset,
or neighboring-page continuity. Borrow only what that role permits. State the
meaning of unfamiliar objects and the direction of each important relationship.

## Prompt Body

```text
Asset: one complete 16:9 PPT slide page image, target 1920x1080, full uncropped page.
Audience and language: <current brief; preserve required names and numeral forms>.
Page purpose: <the audience-facing argument or explanation this page must carry>.
Exact visible copy: <current title, labels, numbers, units and compact sources>.
Composition: <first-glance object; spatial relationships; meaningful connectors>.
Required relationships: <from/to/direction, mandatory gates, parallel vs sequential branches; empty if none>.
Quantity bindings: <quantity, task, input condition, metric/unit, source and intended visual encoding; empty if none>.
Object semantics and treatment: <what each object represents; verified anatomy/modality/plane; bind characters, medical diagrams, tools and lettering to the same selected visual language>.
Evidence: <only this page's supported claims and approved assets>.
Style profile: <profile id from contracts/runtime-program/ppt-native-ai-first-design-pack.json#/professional_style_registry or prompts/ppt_deck/style_profiles.json>.
Style: <resolved palette relationships, lettering, marks, material, depth, whitespace, prompt recipe and forbidden regressions from the selected profile>.
References (optional): <none, or each image's role, allowed borrowing and excluded borrowing; style does not authorize copying scenery, objects or layout>.
Verified assets: <source/hash, reserved region, independent layer and crop; never fabricate evidence>.
Preserve: <required comparisons, facts and neighboring-page continuity>.
Avoid: <page-specific factual and visual failure modes; internal production copy>.
```

The notebook/marker profile is an optional example, not a mandatory style
prefix. User instructions and accepted direction replace its aesthetic and
language choices while retaining source fidelity, legibility and complete-page
requirements. Necessary evidence stays visible; do not enforce a universal
label count, whitespace ratio or card layout.

The selected profile is a reusable visual layer, not a page template. Apply its
material, mark-making, color relationships and lettering while letting the
current page claim choose the composition. The output must still read as a
lecture slide at first glance. If a style prompt makes the page look like an
illustration with text attached, route back to visual direction and repair the
composition before adding more decorative detail.

Verified medical-image/QR/download/UI/paper/logo assets retain their real bytes under the
verified-asset policy. Correct ordinary text, object and composition errors by
prompted redraw, not a deterministic cover-up. Inspect the entire repaired page:
a local edit can change another number, arrow, word or organ.

Before invoking generation, AI reads this brief as an explanation: check that
every necessary relationship and quantity has the intended meaning, visible
copy is audience-facing, and the chosen composition can express both. Do not
send an unresolved semantic contradiction to the image model. Internal field
labels and coordinates are instructions, not additional visible strings.

Bind the selected profile/revision and shared craft prefix to the actual
submitted request across page families. The page payload may change objects,
relationships and composition; it may not silently rewrite the shared craft.
Record actual prompt bytes/hash, shared prefix bytes/hash and each input image's
borrowing scope with that generation. A later edited file is not its request.

## Route Calibration And Fair Comparisons

Use the selected route's demonstrated prompt strategy; an image anchor is not
mandatory. Start with a coherent positive description of craft and then the
current page's relationships and exact copy. References can import unwanted
layout or visual habits, so supply them only for a named need. Clean hand-drawn
animation contours and clear painted planes do not require artificial roughness.
Independent comparisons exclude corresponding finished-page images. Declare
actual image inputs and attempt counts. Keep first-pass evidence honest without substituting a later output.
From-scratch authoring is not a one-attempt hard stop: improve the initial
recipe and continue authorized independent generation until usable. Only an
explicit experiment-only call limit applies that scoped budget.
