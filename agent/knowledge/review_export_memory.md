# Review Export Memory Knowledge

Review, export, and memory decisions are RCA-owned.

AI-first review must inspect rendered evidence:
- final screenshots
- exported pages
- visual director review evidence
- source fidelity and visible copy boundaries
- route-specific packaging evidence

Visual memory writeback requires:
- a rendered artifact evidence ref
- review verdict ref
- proposal ref
- accept/reject owner receipt ref
- intended product, owner, topic or project scope and content kind
- exact source identity and base revision for version-checked writeback

OPL can project readiness gaps and memory receipt coverage, but it cannot accept or reject visual memory.

Accepted lessons return to their single editable source through the common
Framework writeback mechanics. A source in Obsidian and a source in the working
directory follow the same lifecycle. Source drift, expiry or revoked access
invalidates affected current summaries; an old snapshot is historical evidence,
not a substitute for current authorization or required production constraints.
